# QureMed Studio

QureMed Studio is the Windows launcher, app library and update center for QureMed Industries products.

## Stack
- React + TypeScript + Vite
- Electron
- electron-builder for Windows packaging
- GitHub Actions for `.exe` builds

## Planned core
- Product library
- Install / Open / Update states
- Stable / Beta channels
- Release notes
- Local product registry
- Download progress UI
- QureMed account & license surface
- Future developer console integration
