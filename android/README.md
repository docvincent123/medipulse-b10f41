# MedTime by QureMED — Android

MedTime — Android-застосунок для нагадування про прийом ліків.

## Можливості версії 1.1

- реєстрація користувача за ім’ям;
- додавання препарату, дози, часу прийому та залишку;
- точні системні нагадування;
- безперервний звук до відповіді користувача;
- дії «Прийняв», «Відкласти на 10 хв» і «Не прийняв»;
- запис причини пропущеного прийому;
- автоматичне зменшення залишку препарату;
- попередження про низький запас;
- відновлення нагадувань після перезавантаження телефона;
- вбудований рингтон та вибір власного аудіофайлу;
- кнопка перевірки дзвінка в налаштуваннях із тестовим сповіщенням «Прийняти зараз»;
- посилена темна тема без чорного тексту на темних картках;
- архів прийомів по днях зі статусами та причинами пропусків;
- QR-підключення родича;
- QureMED Cloud для віддаленого сімейного доступу через HTTPS;
- родич може оновити графік ліків та останні записи архіву з будь-якого інтернету;
- темний інтерфейс Jetpack Compose у стилі QureMED.

## Родинний доступ

Версія 1.1 підтримує QureMED Cloud. Власник вводить HTTPS-адресу backend на Render, створює приватний онлайн-доступ і показує QR родичу. У QR використовується окремий viewer-токен; owner-токен залишається тільки на телефоні власника. Локальний QR старого формату також підтримується як fallback.

Для реального використання медичних даних потрібна постійна база даних із резервним копіюванням, політика приватності та належні організаційні/правові заходи.

## Локальна збірка

Потрібні JDK 17 та Android SDK 35.

```bash
gradle :app:assembleDebug
```

APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## GitHub Actions

Workflow автоматично збирає debug APK і завантажує artifact з назвою:

```text
MedTime-by-QureMED-Android-APK
```

## Медичне застереження

MedTime нагадує про графік, який вніс користувач. Застосунок не призначає препарати, не змінює дозування та не замінює консультацію лікаря.
